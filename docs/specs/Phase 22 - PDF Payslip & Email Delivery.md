# Phase 22 - PDF Payslip & Email Delivery

## Overview

Phase 22 extends the payroll system by introducing PDF payslip generation, publication, download, and email delivery capabilities.

The implementation builds on top of the existing Payroll, Payroll Approval Workflow, Payslip Management, Tax Engine, and Insurance Engine modules while preserving the snapshot-based payroll architecture.

The primary objective is to provide employees with downloadable and distributable payroll documents without recalculating payroll data.

---

## Goals

* Generate PDF payslips from finalized payroll runs.
* Store payslip document metadata.
* Support secure payslip download.
* Support bulk and individual payslip email delivery.
* Maintain export and delivery auditability.
* Preserve payroll snapshot integrity.
* Avoid recalculating payroll, tax, or insurance during document generation.

---

## Functional Scope

### PDF Generation

Generate PDF payslips from finalized payroll runs.

Each generated document contains:

* Employee information
* Payroll period
* Gross income
* Tax deductions
* Insurance deductions
* Net pay
* Payroll summary information

Generation is idempotent.

Re-generating an existing payslip updates document metadata without duplicating records.

---

### Payslip Document Storage

Store document metadata:

* Document Id
* Payslip Id
* File Name
* Content Type
* Storage Path
* File Size
* Generated At
* Generated By

Physical file storage is abstracted through document storage services.

---

### Payslip Publication

Published payslips become visible to employees.

Publication records:

* Published At
* Published By

Only published payslips may be accessed through employee self-service.

---

### Download Support

Employees may securely download published payslips.

Download handler validates:

* Payslip existence
* Publication status
* Physical file existence

Missing files return a business error instead of runtime exceptions.

---

### Email Delivery

Supports:

* Single employee delivery
* Bulk payroll run delivery

Email delivery includes:

* PDF attachment
* Employee-specific recipient address

Provider abstraction:

* IPayslipEmailSender

Implementations:

* LoggingPayslipEmailSender
* SmtpPayslipEmailSender

SMTP configuration is controlled through HrSettings.

## Technical Notes

* Payslips are generated exclusively from persisted payroll snapshots.
* No payroll recalculation occurs during PDF generation.
* Email delivery uses generated PDF files as attachments.
* Missing physical files are handled gracefully through business validation.
